LA DECISIÓN DETRÁS DEL CÓDIGO

La base de datos protege el stock.

Las APIs no guardan el inventario en memoria. PostgreSQL confirma la referencia, descuenta las unidades y guarda el pedido en una única transacción. Una compra fallida no consume stock ni reserva la referencia.
